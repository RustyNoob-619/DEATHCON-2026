# Glossary: the Frostmarch in plain words

The pack has two voices. The **world voice** carries the story (names, dispatches, flare notes). The **plain voice** carries everything you act on: instructions, search syntax, tab and field names, file names, numbers and rule text. A platform name is never renamed: the tab is "Strings", not "the Ledger".

| In the Frostmarch | Plain meaning |
|---|---|
| the Hold | the corpus: the platform's collection of samples, real ones and this case's together |
| a catch | a sample |
| a net | a YARA rule |
| the mesh | a rule's pattern; "tighten the mesh" means make the pattern more specific |
| cast a net | run a rule in the Pebble Lab (it always runs over the whole Hold) |
| the haul | a rule's hits |
| bycatch | false positives |
| a clean haul | a rule with no false positives |
| a flare | new material released by the facilitator at a set time (an "inject" in exercise jargon) |
| the watch | the exercise session |
| the ice edge | the network perimeter |
| the Warmgrid | the power and district-heat network |
| the Undercurrent | SWORD's covert channel for sharing intelligence |
| the Council | the Floe Assembly's Infrastructure Council, the customer |

| HTA | Hollowvent Thermal Authority, the victim |

| PLC | programmable logic controller |
| TLP | Traffic Light Protocol, the marking that says who may be told |
